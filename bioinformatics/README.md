# FASTA Parser & Sequence Stats

A lightweight Python script to parse FASTA files and calculate basic sequence statistics.
Built to demonstrate core Python skills for bioinformatics and data processing.

## What it does
- Reads multi-line FASTA files
- Extracts sequence ID and full sequence
- Calculates:
    - Sequence length
    - GC content %
    - Base counts (A, T/U, G, C)

## How to run
1. Clone the repo
2. Place your `.fasta` file in the folder
3. Run:
   ```bash
   python fasta_parser.py
