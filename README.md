# Data Science Foundations

A collection of projects showing my work in SQL, Python, and Bioinformatics. 
Built to demonstrate practical coding skills for health and data analysis.

## Projects

### 1. /sql
Employee database queries and data cleaning using SQL.  
Covers SELECT, JOINs, aggregations, and data validation.

### 2. /python  
ATM simulation in Python.  
Demonstrates OOP, control flow, and user input handling.

### 3. /bioinformatics  
FASTA parser and sequence statistics in Python.  
Parses DNA sequences, calculates GC content, length, and base counts.  
Test data included in `/bioinformatics/data/`.

## Skills Demonstrated
- **Languages**: Python, SQL
- **Tools**: Git/GitHub, Pandas, NumPy basics
- **Bioinformatics**: FASTA parsing, sequence analysis
- **Data**: Data cleaning, querying, validation

Each folder has its own README with setup and usage instructions.
