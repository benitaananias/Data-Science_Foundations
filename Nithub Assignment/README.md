# Nithub Assignment

Basic Python loop practice exercises.  
Each task demonstrates `for` loops, conditionals, and `continue`.

## Tasks

1. **Custom message**  
   Loop through a list `["apple", "banana", "cherry"]` and print a custom message for each item.

2. **Vowel count**  
   Take user input and count how many vowels `a, e, i, o, u` are in the word.

3. **Iterate through PYTHON**  
   Iterate through the string `"PYTHON"` and print each letter on a separate line.

4. **Even numbers**  
   Print all even numbers between 1 and 20 using a `for` loop + `if` condition.

5. **Print numbers 1-5**  
   Print numbers 1 to 5 but skip `3` using the `continue` keyword.
