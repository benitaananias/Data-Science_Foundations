Pandas Practice — Employee Salary Analysis

Exploratory data analysis of employee salary dataset using NumPy, pandas, and matplotlib.

What This Covers
- NumPy Operations: Generated 50 random integers 1-100, computed mean/median/standard deviation, extracted min/max values, filtered values >60 and <30
- Pandas Data Exploration: Displayed first 5 rows with `head()`, generated summary statistics using `describe()`
- Data Analysis: Identified job title with highest `salary_year_avg`, counted unique job titles
- Filtering & Sorting: Filtered records where `salary_year_avg` > 70000, sorted job titles by salary descending
- Data Visualization: Bar chart of job title vs `salary_year_avg`, line graph of salary trends with titles and axis labels

Key Skills Demonstrated
NumPy array operations, pandas DataFrame filtering/sorting/groupby, data visualization with matplotlib, statistical analysis, exploratory data analysis workflow.

Dataset
Mock employee salary dataset containing job titles and yearly average salaries. Anonymized for practice purposes.

Tools
- Python: NumPy, pandas, matplotlib
- Environment: Google Colab
