**Topic:** Python Functions

This repo contains solutions for last week's Python functions practice set.

## 📝 Assignment Overview

Write 5 standalone functions that each solve one problem. Each function should take inputs, do the logic, and `return` a result. No `print()` inside the functions.

### Problems

**1. Rectangle Perimeter**  
`perimeter(length, width)`  
Takes the `length` and `width` of a rectangle and returns the total perimeter.  
Formula: `perimeter = 2 * (length + width)`

**2. Ticket Price by Age**  
`ticket_price(age)`  
Takes a person's `age` as an integer.  
Returns `10` if age is 12 or under, otherwise returns `15`.

**3. Username Validation**  
`is_valid_username(username)`  
Takes a `username` string.  
Returns `True` if the username is at least 6 characters long, `False` otherwise.

**4. Even or Odd**  
`even_or_odd(number)`  
Takes an `integer`.  
Returns the string `"Even"` if the number is even, `"Odd"` if it is odd.

**5. Password Strength Check**  
`is_strong_password(password)`  
Takes a `password` string.  
Returns `True` ONLY if both are true:  
- At least 8 characters long, AND  
- Contains at least one `!`  
Otherwise, returns `False`.
